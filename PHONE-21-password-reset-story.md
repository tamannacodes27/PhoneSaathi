# PHONE-21: Password Reset

## User Story
As a learner, I want to reset my forgotten
password using email so that I can regain
access to my account.

## Acceptance Criteria
- The learner can request a password reset.
- The learner receives a password reset email.
- The learner can reset their password securely.
- Invalid or expired reset links are rejected.
- The learner can sign in using the new password.

## Testing
Documentation-only change.
No application code was modified.
