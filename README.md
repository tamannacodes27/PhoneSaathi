# PhoneSaathi

PhoneSaathi helps older adults learn basic smartphone skills. 
For the Milestone-2, we have created a Notes app feature where the user writes what they learnt, makes small to-do lists, 
and keeps a separate 'Skills to Practise' list. 
Each signed-in user's data is saved in Firebase.

## How to open/run
1. Put code/notes.html in the PhoneSaathi project folder, next to firebase.js.
2. Run it with a local server (for example VS Code Live Server).
3. Sign in with Google.
